# 订阅支付完整流程详解

## 📊 流程总览

```
用户点击订阅
    ↓
前端组件处理
    ↓
调用支付 API
    ↓
创建订单
    ↓
调用 Creem API
    ↓
跳转到 Creem 支付页面
    ↓
用户完成支付
    ↓
Creem Webhook 回调
    ↓
处理订单和积分
    ↓
跳转到成功页面
```

#### **2.1 调用 usePayment Hook**

**文件**：`src/hooks/use-payment.ts:33-79`

```typescript
const createCheckout = async (productId: string): Promise<boolean> => {
  setState({ isLoading: true, error: null, checkoutUrl: null });

  try {
    // 调用后端 API
    const response = await fetch("/api/payments", {
      method: "POST",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify({ product_id: productId }),
    });

    const result: PaymentResponse = await response.json();

    if (!result.ok || !result.data?.checkout_url) {
      throw new Error(result.message || "支付请求失败");
    }

    // 自动跳转到 Creem 支付页面
    window.location.href = result.data.checkout_url;
    return true;
  } catch (error) {
    setState({ isLoading: false, error: errorMessage, checkoutUrl: null });
    return false;
  }
};
```

#### **5.2 验证 Webhook 签名**

**文件**：`src/app/api/pay/callback/creem/route.ts:50-76`

```typescript
const payload = await request.text();
const signature = request.headers.get('creem-signature');

const webhookSecret = process.env.CREEM_WEBHOOK_SECRET;
if (webhookSecret && signature) {
  const hmac = createHmac('sha256', webhookSecret);
  hmac.update(payload);
  const computedSignature = hmac.digest('hex');
  
  if (computedSignature !== signature) {
    console.error('Signature verification failed');
    return NextResponse.json({ error: '签名验证失败' }, { status: 400 });
  }
}
```

## ⚠️ 错误处理

### **常见错误场景**

1. **用户未登录**
   - 返回 401，提示登录

2. **产品 ID 无效**
   - 返回 400，提示产品不存在

3. **Creem 产品映射缺失**
   - 返回 500，提示配置错误

4. **Webhook 签名验证失败**
   - 返回 400，拒绝处理

5. **订单未找到**
   - 记录错误日志，返回 404

6. **积分发放失败**
   - 回滚订单状态，记录错误
